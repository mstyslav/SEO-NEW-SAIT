# Project guidance for Claude Code sessions

## SEO work protocol (Space Glass)
Before any SEO task:
1. Read `docs/SEO-ROADMAP.md` (register: `docs/SEO-ROADMAP.csv`) and check the status of related items.
2. Avoid duplicate work; do not edit pages marked as protected/SCHEDULED for measurement.
3. Execute the assigned task; make only evidence-based changes; never invent prices, projects, dates or data.
4. Update the roadmap (both `.md` and `.csv`): status, next action, target date, evidence (commit SHA / PR / report path), last updated.
5. Record new dependencies as new roadmap items.
6. Owner-only decisions go to `docs/SEO-OWNER-ACTIONS.md`; follow-up tasks to `docs/SEO-NEXT-TASKS.md`.
7. Public repository: do not commit GSC/GA4 performance data or private business data.
