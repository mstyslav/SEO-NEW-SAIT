# Production Fix 5

## Виправлення конфігуратора

Причина: на сторінці товару `safeNumber` викликався до оголошення. Через
JavaScript ReferenceError код зупинявся до підключення обробників кнопок.

Виправлено:
- `safeNumber` перенесено вище першого використання;
- вибір опцій працює через делегований click-handler;
- додано `aria-pressed`;
- курс НБУ має безпечний fallback;
- така сама стабілізація додана до універсального конфігуратора;
- доданий regression check.
